# Personal Assistant

A personal assistant that lets two users chat with Claude through WhatsApp, receive email summaries and get usage alerts.

## Tech stack

- ASP.NET Core (C#)
- SQLite with Entity Framework Core
- WhatsApp Cloud API (Meta)
- Claude API (Anthropic)

## Roadmap

- [ ] Phase 1: Chat through WhatsApp
- [ ] Phase 2: Memory and project context
- [ ] Phase 3: Email summaries
- [ ] Phase 4: Production hosting and usage alerts

## Configuration

All tokens and API keys are stored with .NET user secrets and are never committed to this repository.
